- 11/11 route có đối chiếu H1/H2/H3, vị trí/kích thước heading và document height giống live ở 2 viewport.
- Import HTML bản đã sửa icon/URL assets của 11 trang được xác nhận không có cảnh báo asset từ Stitch.
- DOM geometry = 0px **không có nghĩa** tất cả pixel, ảnh động, tương tác hoặc API đều giống: cần screenshot diff, kiểm thử menu/CTA/filter/form.
- Screenshot tiếng Việt toàn trang: desktop 1280×900 và mobile 390×844; 22 ảnh tham chiếu + trạng thái UI được giữ riêng.
- V1 chưa được phê duyệt final. Không phát triển V2 trên bản clone AI chưa QA; chỉ sử dụng bản HTML VI source làm nền.
