## Confirmed failures

1. PHP 8080 does not expose /api/pts_v1_public_route_resolve.php (HTTP 404 HTML).
   PHP 8088 does expose it and returns JSON. With Nuxt configured to PHP 8080,
   /_migration/resolve-public-slug?slug=duoc-gi-khi-hop-tac-cung-phuc-thinh-solar
   returns 502 Public route resolver unavailable.
2. PHP 8088 resolver returns canonicalPath, while Nuxt contract
   frontend/shared/contracts/public-route-resolution.ts requires canonical.
   With Nuxt configured to PHP 8088, the same bridge returns 502
   Invalid public route resolution contract. News/project legacy slug SSR routes
   consequently rendered 502 in the runtime smoke.
3. /_migration/product-detail?slug=unknown-slug returns 502 although PHP returns
   404 PRODUCT_NOT_FOUND; product-detail.get.ts does not pass through 404.
4. Direct Nuxt origin requests to /upload/* and /assets/* returned 404 preview
   media in Playwright. This is expected only when Caddy/media proxy is present;
   a full cutover smoke must run through the Caddy route that forwards legacy media
   to PHP. Direct Nitro must not be used as the public production origin.

## SSR route smoke

With PHP origin 8080, list routes returned 200, but bare news/project routes
returned 502 because the resolver endpoint is absent. With PHP origin 8088,
the same routes still returned 502 because the preview DTO used canonicalPath
while the Nuxt validator requires canonical. Static product and solution routes
returned 200. The browser console also logged only expected preview-media 404s
when running direct Nitro without Caddy.
